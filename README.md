## 🌟 Key Features

- **Dynamic Interactive Canvas**: Custom particle background network reacting dynamically to mouse proximity and screen resizing.
- **Magnetic Custom Cursor**: Spring-based trailing cursor with interactive scaling on buttons and cards.
- **Dark & Light Mode**: High-contrast theme engine with persistence.
- **Interactive Web Audio Effects**: Subtle sound blips and celebration feedback generated via Web Audio API.
- **Hero Terminal Card**: Dynamic role typing effect, live availability status, and direct CTA actions.
- **Career Timeline**: Animated vertical progression displaying roles at *Innodata*, *Pitavya*, *White Circle Group*, and *Ultraxpert*.
- **Skill Matrix & Search**: Filterable and searchable technology matrix with animated progress bars.
- **Projects Showcase & Architecture Deep-Dive**: In-depth inspection modal with full pipeline diagrams and metrics for:
  - *AI Real-Time Voice Agent* (FastAPI, Whisper STT, Azure Neural TTS, WebSockets)
  - *Kamai-Kharcha Expense Management Platform* (React, Node.js, Express, MongoDB, AWS S3/SES)
  - *Skill Eval Education Platform* (React, Modular components, dynamic test state)
  - *DocuMind Intelligent RAG Assistant* (FastAPI, LangChain, Vector DB)
- **Live AI Voice Agent Simulator**: Hands-on interactive prototype simulating WebSocket speech streaming and neural synthesis.
- **Achievements Counter**: Intersection-observer animated metrics.
- **Interactive Contact Form**: Client-side validation with canvas-confetti celebration upon sending.
- **Printable Resume Viewer**: Dedicated modal with `@media print` styling for 1-click clean PDF export.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/KritiRawani/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
